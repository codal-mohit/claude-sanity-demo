# Claude Code Demo

Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4 and Vitest.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run verify   # lint, typecheck, tests
```

## Scripts

- `npm run dev`: start the dev server
- `npm run build` / `npm run start`: production build and server. Do not run `build` while `dev` is running.
- `npm run lint`: ESLint
- `npm run typecheck`: `tsc --noEmit`
- `npm run test`: Vitest, single run
